# Uploadimgeo

דף אינטרנט (עמוד יחיד — `index.html`) להעלאת תמונות, שלפני ההעלאה או האריזה שלהן מחלץ מכל תמונה את נתוני המיקום (GPS) ושאר נתוני ה-Exif הזמינים (תאריך צילום, דגם מצלמה, עדשה, חשיפה וכו').

כל העיבוד מתבצע בצד הלקוח (בדפדפן) — אין צורך בשרת כדי לצפות בנתוני המטא-נתונים.

## מה הדף עושה

1. גרירה/בחירה של תמונות.
2. חילוץ אוטומטי של Exif ו-GPS מכל תמונה (באמצעות [exifr](https://github.com/MikeKovarik/exifr)) והצגתם בכרטיס לכל תמונה.
3. הצגת כל התמונות בעלות מיקום על מפה (Leaflet + OpenStreetMap).
4. ייצוא המטא-נתונים שנאספו כ-JSON או CSV.
5. אריזת התמונות (עם אפשרות להסרת ה-Exif מהקבצים עצמם, כברירת מחדל) יחד עם קובץ מטא-נתונים לקובץ ZIP אחד להורדה.
6. אפשרות אופציונלית להעלות את החבילה (תמונות + מטא-נתונים) לכתובת שרת (`POST` בפורמט `multipart/form-data`), אם הוגדרה כתובת endpoint.

## פרסום ב-GitHub Pages

הריפו כולל workflow ב-`.github/workflows/pages.yml` שמפרסם אוטומטית את הדף ל-GitHub Pages בכל push לענף `main`.

להפעלה חד-פעמית:

1. מיזגו את הענף הזה ל-`main`.
2. בהגדרות הריפו: `Settings → Pages → Build and deployment → Source` בחרו **GitHub Actions**.
3. לאחר ה-push הבא ל-`main`, הדף יהיה זמין בכתובת `https://<username>.github.io/Uploadimgeo/`.

לחלופין ניתן לפרסם ישירות מהענף (`Settings → Pages → Deploy from a branch`) ולבחור את הענף ותיקיית השורש (`/`), מכיוון שמדובר בקובץ `index.html` סטטי יחיד.
